# STEEL PLAN · 철골 발주 및 절단 최적화

엑셀 BOM에서 **재질·규격·길이·수량**을 읽어 발주 원자재 목록과 CUTTING PLAN을 만드는 Python 웹 앱입니다. Python 3.11~3.13을 권장하며, 이 환경에서는 Python 3.12로 검증했습니다.

## 빠른 실행

저장소 폴더에서 실행하세요. 첫 설치에는 인터넷 연결이 필요하고, 실행 후 계산과 파일 출력에는 외부 API·DB·키가 필요하지 않습니다.

### Windows

Python을 설치한 뒤 `run.bat`을 실행하거나 명령 프롬프트에서:

```bat
run.bat
```

### macOS / Linux

```bash
bash run.sh
```

브라우저에서 **http://127.0.0.1:8000**을 열어 사용합니다. 종료는 실행 터미널에서 `Ctrl+C`입니다. 실행 스크립트는 `.venv` 생성 및 의존성 설치를 수행합니다.

### 직접 설치 및 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Windows에서 가상환경 활성화 명령은 `.venv\Scripts\activate`입니다. 소스 수정 시 자동 재시작하려면 uvicorn 명령에 `--reload`를 추가합니다. 설치가 끝난 후에는 uvicorn 명령만으로 다시 실행할 수 있습니다.

원격 개발 환경에서는 `--host 0.0.0.0`을 사용하고 해당 환경의 포트 전달 기능으로 접속합니다. 실행 스크립트의 호스트·포트는 `STEELPLAN_HOST`, `STEELPLAN_PORT`로 바꿀 수 있습니다. 개인용 로컬 서버이며 일반 사용자별 데이터 분리는 없습니다. 관리자 설정의 외부 변경에는 아래 관리자 비밀번호가 필요합니다.

## 사용 순서

1. **샘플로 시작하기**를 누르거나 `.xlsx` BOM을 업로드합니다. [샘플 BOM](examples/sample_bom.xlsx)도 제공합니다.
2. 시트와 헤더 행을 확인합니다. 일반적인 한글·영문 헤더는 자동 인식합니다. 자동 인식이 안 되면 **헤더 행 → 열 다시 읽기 → 열 지정 → BOM 읽기** 순으로 진행합니다.
3. 미리보기의 재질·규격·길이·수량을 확인합니다.
4. DESCRIPTION을 기준으로 자재 종류와 발주 길이가 자동 적용됩니다. 예외가 없으면 최적화 버튼이 바로 활성화됩니다. 예외가 있으면 원본 행·부재 번호·규격·길이·원인을 확인하고 **예외 부재를 모두 제외하고 정상 데이터만 계산**을 직접 선택하거나 BOM·관리자 설정을 수정합니다. 모든 부재가 예외이면 계산할 수 없습니다.
5. **원자재 리스트**와 **조합 리스트** 탭에서 결과를 확인하고 **A4 가로 / A3 가로**를 고른 뒤 **엑셀 저장 / PDF 저장**을 선택합니다. 결과가 나오면 입력 영역을 접어 넓은 표를 표시합니다.

입력이나 조건을 변경하면 이전 결과를 숨깁니다. 변경 후 다시 계산해야 내보낼 수 있습니다.

## 자재 분류 및 발주 길이

| 자재 종류 | DESCRIPTION 예 | 기본 발주 길이 (mm) |
|---|---|---|
| H빔 | `H300*300*10*15`, `H-300×300×10×15` | 8000, 9000, 10000, 11000, 12000, 13000, 14000, 15000, 16000 |
| 각파이프 | `P100*100*4`, `P100*50*4` | 6000 고정 |
| 잔넬 | `[125*65*6*8` | 10000 고정 |
| 앵글 | `L65*65*5` | 10000 고정 |
| C형강 | `C150*75*20*3.2` | 10000 고정 |
| 환봉 | `D19` | 6000 또는 8000 |

등록된 숫자 치수 형식만 분류합니다. `PLT`, `PIPE` 등은 **미지원 자재**이며 임의로 다른 자재에 배정하지 않습니다. 발주 길이를 다른 종류에서 빌려 쓰거나 부재를 임의 분할하지 않습니다. 예를 들어 각파이프 6184mm는 6000mm 초과이므로 **발주 가능 길이 초과** 예외입니다. 절단 길이가 허용 길이 이내여도 날 손실과 잔재 > 30mm를 확보하지 못하면 별도의 **절단 손실·잔재 조건** 예외입니다.

**관리자 설정 · 발주 길이 수정**에서 종류별 길이를 쉼표로 입력하고 저장할 수 있습니다. 각 종류 1~20종, 30mm 초과·100,000mm 이하·소수점 셋째 자리까지 허용하며, **각파이프는 6000mm로 고정**합니다. 저장 후 자동으로 BOM을 재검사합니다. 설정은 `data/stock_settings.json`에 원자적으로 저장되어 서버 재시작 후에도 유지되고 Git에는 포함되지 않습니다. 파일이 없으면 위 기본값을 사용하며, 손상된 파일은 오류를 표시하고 임의로 초기화하지 않습니다.

관리자 설정 쓰기는 기본적으로 서버의 루프백 접속에서만 허용합니다. 외부·프록시 접속에서 수정하려면 서버 실행 전에 **STEELPLAN_ADMIN_PASSWORD** 환경 변수를 설정하고 화면에 해당 비밀번호를 입력하세요. 비밀번호가 설정되면 로컬에서도 입력해야 합니다. 비밀번호를 소스·Git에 저장하지 마세요. 이 설정 보호는 계정·사용자별 권한 시스템을 대신하지 않습니다.

제외 동의는 확인한 BOM·날 손실·발주 설정에만 유효합니다. 다른 사용자가 설정을 바꾸는 등 예외 대상이 달라지면 서버도 계산을 중단하고 최신 예외 목록에 대한 재확인을 요구합니다. 결과의 생산 수량과 제외 수량 합계는 원본 BOM 수량과 일치합니다.

## 실제 TS ASSEM LIST 양식

[TS ASSEM LIST 예제](examples/ts_assem_sample.xlsx)는 정상 6종과 각파이프 6184mm·미지원 PLT 예외를 함께 포함합니다. 업로드 시 **TS ASSEM LIST** 시트를 우선 선택하고 1행 헤더를 자동 매핑합니다.

| 열 | 헤더 | 용도 |
|---|---|---|
| A | ITEM | 부재 분류 보존 |
| B | TITLE | 부재 번호 및 예외 추적 |
| C | MATL | 재질 |
| D | DESCRIPTION | 규격 및 자재 종류 판별 |
| E | LENGTH | 절단 길이 (mm) |
| F | QTY | 수량 |
| G | WEIGHT.KG | 원본 중량 보존 (최적화에는 사용하지 않음) |
| H | PAINT.M | 원본 도장 면적 보존 (최적화에는 사용하지 않음) |

2행부터 데이터를 읽고 원본 행 번호를 유지합니다. 재질·규격의 불필요한 공백은 제거하고 부재 번호 등 문자열의 앞뒤 공백을 정리합니다. 빈 행과 마지막 `TOTAL / 합계 / 총계` 등의 합계 행은 제외합니다. 합계 행은 합계 표시와 빈 절단 길이 또는 빈 규격으로 식별하므로 TITLE이 TOTAL인 정상 부재를 임의로 제거하지 않습니다.

## BOM 양식

| 재질 | 규격 | 길이 (mm) | 수량 |
|---|---|---:|---:|
| SS275 | H-300×300×10×15 | 3500 | 6 |
| SS275 | H-300×300×10×15 | 2400 | 8 |
| SM355 | H-400×200×8×13 | 4200 | 4 |

- 자동 인식 예: `재질/강종/Material/Grade`, `규격/Spec/Section/Size`, `길이/길이 (mm)/Length (mm)`, `수량/Qty/Quantity`.
- `.xlsx`만 지원합니다. `.xls`, CSV는 Excel에서 `.xlsx`로 변환하세요. 여러 시트 중 선택한 **한 시트**를 계산합니다.
- 모든 길이는 **mm**, 소수점 셋째 자리까지 지원합니다. 수량은 1~5,000의 정수입니다. `2,400` 같은 숫자 문자열도 읽습니다. 길이 셀에 `2400mm`처럼 단위를 붙이지 마세요.
- 최대 업로드 10MB, 압축 해제 합계 50MB, 데이터 1,000행, 총 부재 5,000개, 재질·규격 그룹 100개입니다. 행·열 탐색은 첫 30개 시트, 첫 100개 열이며 자동 헤더 탐색은 첫 30행, 수동 헤더 지정은 100행까지입니다. 데이터 읽기 자체도 10,000행 이내로 제한합니다.
- 재질·규격의 공백을 제거한 뒤 정확히 일치하는 문자열끼리 그룹화합니다. 대소문자 및 `x / × / *` 표기를 임의로 바꿔 합치지 않으므로 업로드 전에 표기를 통일하세요.
- 필수 필드 누락이나 수량·숫자 오류는 **전체 불러오기를 중단**하고 최대 50개까지 표시합니다. 자재 미지원·길이 초과·잔재 조건 예외는 별도 목록을 제공하며 직접 제외를 선택할 수 있습니다. 병합 셀은 각 행에 값을 채워 주세요.
- 수식은 실행하지 않고 Excel이 저장한 계산 결과를 읽습니다. 값이 없는 수식은 Excel에서 재계산 후 저장하거나 값으로 붙여넣으세요.

## 최적화 규칙

재질과 규격이 모두 같은 부재끼리만 절단합니다. 동일 길이의 중복 BOM 행은 합산하며, 입력 수량을 초과·미달 생산하지 않습니다. 절단하는 원자재 1본은 다음을 만족해야 합니다.

```text
제품 길이 합계 + 절단날 손실 × 부재 개수 + 잔재 = 원자재 길이
잔재 > 30mm
```

**잔재가 0~30mm인 조합은 정확히 맞는 조합을 포함해 모두 금지**됩니다. 0.001mm 정수 단위로 계산하므로 최소 허용 잔재는 30.001mm입니다. 예를 들어 6,000mm 원자재에서 부재 5,967mm를 절단하고 날 손실이 3mm이면 잔재가 30mm이므로 사용할 수 없습니다. 5,966.999mm이면 잔재 30.001mm로 허용됩니다.

날 손실 기본값은 **3mm/부재**이며 각 부재에 절단 1회를 적용합니다. 날 손실을 고려하지 않을 때는 0으로 설정합니다. 선단 트리밍·양끝 여유·가격·절단 순서 제약·별도 보유 잔재 재고는 모델링하지 않습니다. 중량 표시는 아래의 명시적 BOM 중량 해석만 사용하며 절단 최적화 목적함수에는 영향을 주지 않습니다.

목적함수는 다음 우선순위를 따릅니다.

1. **발주 본수 최소화**
2. 동일 본수에서 **총 발주 길이 최소화** (= 제품 소요량이 고정일 때 총 로스 길이 및 전체 로스율 최소화)

따라서 본수를 더 쓰면 로스가 작아지는 경우에도 본수 최소화가 우선합니다. 원자재 단가를 사용한 비용 최적화는 아닙니다.

```text
로스 길이 = 잔재 + 절단날 손실
로스율 (%) = (총 발주 길이 − 총 제품 길이) / 총 발주 길이 × 100
```

OR-Tools CP-SAT 정수계획법을 사용합니다. 먼저 실행 가능한 조합을 구하고, 그룹별로 전체 제한 시간을 나눠 더 좋은 조합을 탐색합니다. **최적해 증명 완료**는 본수와 총 길이에 대한 최적성이 증명된 경우입니다. 시간 제한 또는 모델 크기 제한(후보 본수 × (길이 종류 + 발주 길이 종류) > 30,000)에 도달하면 **실행 가능 해 · 최적해 미확정**으로 표시합니다. 이 경우 더 좋은 조합이 있을 수 있습니다. 시간 설정은 탐색 시간 예산이며 모델 생성·파일 출력 시간은 추가될 수 있습니다. 반환 전 수량과 잔재 규칙을 별도로 재검증합니다.

## 출력 파일

- **엑셀**: `원자재 리스트`, `조합 리스트`, `BOM`, `계산 설정`, `계산 제외 부재` 5개 시트. A4/A3 가로, 반복 머리글과 페이지 번호를 지원합니다. 자재 종류·원본 행·부재 번호·중량·도장 면적·포함 여부·종류별 허용 길이 및 제외 원인을 포함합니다. 필터·헤더 고정·인쇄 설정을 유지합니다.
- **PDF**: A4 또는 A3 가로, 원자재 리스트와 조합 리스트를 별도 구역으로 출력합니다. 열 순서는 화면·엑셀과 동일하며, 머리글·규격 구분 반복, 페이지 번호 및 제외 부재 목록을 포함합니다. 한글 글꼴을 파일에 포함합니다.
- 같은 절단 조합은 반복 본수로 묶습니다. 조합 리스트의 등분·조합길이·날 손실·잔철는 **원자재 1본 기준**입니다. 전체 소요량은 반복 본수를 곱합니다.
- 파일은 서버 메모리의 실제 계산 결과에서 생성합니다. 결과는 최대 **1시간 / 최근 20건**, 서버 재시작 시 삭제됩니다. 다중 워커를 사용하지 마세요. 영구 저장소나 계산 이력 기능은 없습니다.

```bash
python -m pytest -q
```

테스트는 잔재 30mm 경계와 소수점, 날 손실, 재질·규격 분리, BOM 수량 보존, 본수 우선·총 길이 최소, 시간 제한 대체 조합, 작은 무작위 입력의 완전탐색 대조, 열 자동/수동 인식, 잘못된 BOM 차단, 엑셀 수량·잔재, PDF 한글 글꼴 포함, 결과 만료, 엑셀 수식 주입 방지를 검증합니다.

기존 20개 테스트 시나리오를 유지하고 API 테스트의 입력·출력 기대값을 종류별 자동 길이 및 제외 시트에 맞췄습니다. 신규 테스트는 6종 분류·고정 길이·실제 BOM·공백/합계 처리·부재 번호 보존·길이 초과·동의 없는 제외 방지·동의 후 수량 보존·관리자 저장/인증·설정 변경 시 재동의를 검증합니다.

기존 샘플의 **새 기본 설정** 결과: **48개 부재 / 원자재 12본 / 총 발주 길이 136,000mm / 제품 122,200mm / 날 손실 144mm / 잔재 13,656mm / 로스율 10.15%**. 동일한 최적값을 갖는 절단 패턴의 구성은 실행마다 달라질 수 있습니다.

## 결과표 열과 집계 기준

원자재 리스트의 열 순서는 **재질 / 규격 / 길이 / 수량 / 총중량 kg / 조합길이 / 조합중량 kg / 잔철 / 사용율 %**입니다. 재질·규격별 소계와 전체 합계를 표시합니다. 일반 행의 길이는 원자재 1본 길이이며, 조합길이와 잔철은 그 행의 발주 수량 전체 합계입니다. 소계·합계 행의 길이는 `길이 × 수량`의 합, 사용율은 전체 길이로 가중한 `조합길이 / 발주 길이 × 100`입니다. 사용율을 단순 평균하지 않습니다.

조합 리스트의 열 순서는 **번호 / 원자재 / 수량 / 조합길이 / 잔철 / 사용율 % / 길이 / 등분 / 총수량 / 비고**입니다. 재질·규격별 표와 동일 패턴별 그룹을 사용합니다. 화면·엑셀은 공통 6열을 세로 병합하고 PDF는 같은 번호와 배경색으로 그룹을 표시합니다. PDF에서 표가 다음 페이지로 이어지면 규격 제목과 머리글을 반복합니다.

- `원자재`, `조합길이`, `잔철`: 원자재 1본 기준 mm.
- `수량`: 해당 절단 패턴을 사용하는 원자재 본수.
- `길이`: 해당 행의 절단 길이 mm.
- `등분`: 원자재 1본에서 해당 길이로 절단하는 개수.
- `총수량`: `등분 × 원자재 수량`.
- `비고`: 원본 BOM 부재 번호와 그 번호에 배정한 **총수량**. 한 길이에 여러 BOM 번호가 있으면 각각 표시하며 중복 배정하지 않습니다.

원본 완성 부재 수량은 `계산 포함 + 사용자 동의 후 제외 = 입력 BOM`으로 검증합니다. 모든 제작 절편도 원본 행에 배정하고 조합 리스트 총수량과 대조합니다. 제공 TS 샘플의 기본 모드 검증값은 입력 17개 = 계산 15개 + 제외 2개이며 조합 리스트 총수량은 15개입니다. 실제 사용자 BOM은 첨부되지 않았으므로 해당 파일의 수량을 검증한 것은 아닙니다.

### 중량은 확인된 정보만 표시

`WEIGHT.KG 해석`의 기본값은 **미지정**이며 중량은 공란입니다. 사용자가 `행 전체 중량` 또는 `부재 1개당 중량`을 직접 지정한 경우에만 BOM 값으로 조합중량을 계산합니다. 하나라도 중량이 누락·오류이면 관련 합계도 공란이며 일부 값만 합산해 전체 중량처럼 표시하지 않습니다. 원자재 kg/m·밀도·도면 단위중량을 입력받지 않으므로 **원자재 총중량은 공란**입니다. BOM 중량으로 원자재 단위중량을 역산하거나 추정하지 않습니다.

## 선택형 이음 제작 검토

**기본 모드에서는 6000mm 초과 각파이프를 ‘발주 길이 초과’ 목록으로 표시합니다. 분할·용접·자동 제외하지 않습니다.** 사용자가 별도로 `이음 제작 검토 계획 포함`을 켰을 때만 아래 기능을 사용합니다.

- 확인된 기본값: 무절단 6000mm 통재 본재, 이음 제작 여유 **5mm/이음**, 재사용 원본 잔재의 최소 길이 **5mm**. 실제 연결재 절단 후에는 항상 **30mm 초과** 잔재를 남겨야 하므로 단지 5mm 이상이라고 사용할 수 있는 것은 아닙니다.
- 6184mm 부재 1개는 본재 6000mm + 연결재 189mm − 이음 여유 5mm로 검토합니다. 날 손실은 연결재 절단에 별도로 적용합니다.
- 같은 작업의 일반 절단 계획에서 발생하는 **동일 재질·규격**의 적합한 잔재를 연결재에 먼저 배정합니다. 부족한 연결재는 기존 CP-SAT 엔진으로 추가 6m 발주를 계산합니다. 본재용 통재와 연결재용 추가 발주를 원자재 리스트에 모두 합산합니다. 별도 보유 잔재 재고를 사용하는 기능은 아닙니다.
- 통재 본재·통재 연결재는 절단 작업이 없으므로 날 손실과 잔철이 0입니다. **실제 절단 조합**은 기존의 날 손실 및 잔재 >30mm 규칙을 유지합니다.
- 원본 부재 번호별 완성 길이, 본재 길이, 연결재 길이, 통재 수, 이음 수와 상태를 조합 리스트에 표시합니다. 긴 부재는 여러 통재와 연결재로 검토하므로 이음 위치·최소 연결재 길이·연결 상세를 별도로 검토해야 합니다. 프로그램이 구조 상세를 설계하거나 승인하지 않습니다.
- 이음 상세 승인 체크 전에는 **검토 필요 · 제작 확정 아님**입니다. 체크 후에도 상태는 사용자 승인 입력 사실을 표시합니다.
- 이음 모드는 일반 절단 최적화 → 적합 잔재 우선 배정 → 부족 연결재 최적화 순서입니다. 단계 전체의 최적성은 증명하지 않으므로 **최적해 미확정**으로 표시합니다. 기본 절단 엔진과 일반 모드의 최적성 판정은 유지합니다.
- 완성 부재 수량과 제작 절편 수량을 별도로 표시합니다. `제작 절편 길이 − 이음 제작 여유 합계 = 완성 부재 길이`를 검증합니다. 총 로스율은 날 손실+잔철 기준이며, 이음 여유까지 포함한 **순 로스율**을 별도로 표시합니다.
- 이음 모드 엑셀에는 `이음 제작 검토`, `잔재 재사용` 시트도 추가합니다. 중량을 임의 배분하지 않으므로 이음 절편의 조합중량은 공란입니다.

참조용 `CP_조합리스트.pdf`, `CP_원자재물량집계표.pdf`는 첨부되지 않아 지정된 열·그룹핑 규칙을 기준으로 구현했습니다. 추후 파일이 제공되면 선·글꼴·제목·여백 등 세부 양식을 맞출 수 있습니다.
