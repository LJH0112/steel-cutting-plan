# STEEL PLAN · 철골 발주 및 절단 최적화

엑셀 BOM에서 **재질·규격·길이·수량**을 읽어 발주 원자재 목록과 CUTTING PLAN을 만드는 Python 웹 앱입니다. Windows 실행 스크립트는 **Python 3.13**을 사용하며, 이번 변경은 Python 3.13.5에서 검증했습니다.

## 빠른 실행

저장소 폴더에서 실행하세요. 첫 설치에는 인터넷 연결이 필요하고, 실행 후 계산과 파일 출력에는 외부 API·DB·키가 필요하지 않습니다. 업데이트는 서버를 종료하고 `git pull origin main`을 실행한 뒤 실행 스크립트를 다시 시작하고 브라우저를 새로고침하세요.

### Windows

Python 3.13과 Windows Python Launcher를 설치한 뒤 `run.bat`을 실행하거나 명령 프롬프트에서:

```bat
run.bat
```

`run.bat`은 `py -3.13`으로 버전을 확인하고 전용 `.venv-py313` 환경을 만듭니다. 기존 `.venv`는 보존하며 다른 Python 버전으로 자동 실행하지 않습니다. Python 누락·가상환경 버전 오류·설치 오류·서버 실행 오류 시 메시지를 출력하고 `pause`로 창을 유지합니다. 이 저장소의 배치 파일은 Git 체크아웃 시 CRLF 줄바꿈을 사용합니다. Linux 환경에서 Python 3.13 의존성 설치와 서버 실행을 검증했으며 Windows CMD 자체 실행은 수행하지 못했습니다.

### macOS / Linux

```bash
bash run.sh
```

브라우저에서 **http://127.0.0.1:8000**을 열어 사용합니다. 종료는 실행 터미널에서 `Ctrl+C`입니다. 실행 스크립트는 `.venv` 생성 및 의존성 설치를 수행합니다.

### 직접 설치 및 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Windows에서 가상환경 활성화 명령은 `.venv\Scripts\activate`입니다. 소스 수정 시 자동 재시작하려면 uvicorn 명령에 `--reload`를 추가합니다. 설치가 끝난 후에는 uvicorn 명령만으로 다시 실행할 수 있습니다.

원격 개발 환경에서는 `--host 0.0.0.0`을 사용하고 해당 환경의 포트 전달 기능으로 접속합니다. 실행 스크립트의 호스트·포트는 `STEELPLAN_HOST`, `STEELPLAN_PORT`로 바꿀 수 있습니다. 개인용 로컬 서버이며 일반 사용자별 데이터 분리는 없습니다. 관리자 설정의 외부 변경에는 아래 관리자 비밀번호가 필요합니다.

## 사용 순서

1. 보고서에 표시할 공사명·공사구분·날짜를 입력한 뒤 실제 `.xls`/`.xlsx` BOM을 업로드합니다. 기존 양식의 [샘플 BOM](examples/sample_bom.xlsx)도 제공합니다.
2. **실제 BOM.xls는 TS BOM LIST만 사용**하며 시트·헤더·열 매핑은 고정됩니다. 해당 시트가 없는 `.xls`는 다른 시트로 대체하지 않습니다. 기존 `.xlsx` 호환 양식에서만 시트·헤더·열을 수동으로 지정할 수 있습니다.
3. 미리보기의 재질·규격·길이·수량을 확인합니다.
4. **TS BOM LIST는 PROFILE 기준 H빔·잔넬·C형강·환봉·T바 5종**만 최적화합니다. 가져오기 제외 내역을 펼쳐 다른 시트·대상 외 자재·조립 요약행을 확인합니다. 예외가 없으면 최적화 버튼이 활성화됩니다. 길이·잔재 조건 또는 T바 길이 미설정 예외가 있으면 원본 행·Part Mark·규격·길이·원인을 확인하고 **예외 부재를 모두 제외하고 정상 데이터만 계산**을 직접 선택하거나 설정을 수정합니다. 기존 양식의 6m 초과 각파이프 이음 검토 기능은 유지하며, TS BOM LIST에서 각파이프는 대상 외이므로 이음 제작에도 들어가지 않습니다.
5. **원자재 리스트**와 **조합 리스트** 탭에서 결과를 확인하고 **A4/A3 및 세로/가로**를 고른 뒤 **엑셀 저장 / PDF 저장**을 선택합니다. 결과가 나오면 입력 영역을 접어 넓은 표를 표시합니다. 기본은 첨부 양식과 같은 A4 세로이며, PDF는 통합·원자재·조합 구역을 선택해 저장합니다.

입력이나 조건을 변경하면 이전 결과를 숨깁니다. 변경 후 다시 계산해야 내보낼 수 있습니다.

## 자재 분류 및 발주 길이

| 자재 종류 | DESCRIPTION 예 | 기본 발주 길이 (mm) |
|---|---|---|
| H빔 | `H300*300*10*15`, `H-300×300×10×15` | 8000, 9000, 10000, 11000, 12000, 13000, 14000, 15000, 16000 |
| 각파이프 | `P100*100*4`, `P100*50*4`, `TS100x100x3.2` | 6000 고정 |
| 잔넬 | `[125*65*6*8` | 10000 고정 |
| 앵글 | `L65*65*5` | 10000 고정 |
| C형강 | `C150*75*20*3.2` | 10000 고정 |
| 환봉 | `D19`, `ROD19` | 6000 또는 8000 |
| T바 | `T100*50*5`, `T100*50*5*7` | **미설정 · 관리자가 승인된 길이 입력** |

등록된 숫자 치수 형식만 분류합니다. `PLT`, `PIPE` 등은 **미지원 자재**이며 임의로 다른 자재에 배정하지 않습니다. 발주 길이를 다른 종류에서 빌려 쓰지 않습니다. 예를 들어 각파이프 6184mm는 본재 6000mm와 연결재 189mm, 이음 제작 여유 5mm로 검토합니다. 이음 위치·연결 상세는 승인 대상이며 승인 전에는 제작 확정이 아닙니다. 사용자가 이음 제작 검토를 끈 경우에만 6000mm 초과를 **발주 길이 초과** 예외로 표시합니다. 절단 길이가 허용 길이 이내여도 날 손실과 잔재 > 30mm를 확보하지 못하면 별도의 **절단 손실·잔재 조건** 예외입니다.

**관리자 설정 · 발주 길이 수정**에서 종류별 길이를 쉼표로 입력하고 저장할 수 있습니다. 각 종류 1~20종, 30mm 초과·100,000mm 이하·소수점 셋째 자리까지 허용하며, **각파이프는 6000mm로 고정**합니다. 저장 후 자동으로 BOM을 재검사합니다. 설정은 `data/stock_settings.json`에 원자적으로 저장되어 서버 재시작 후에도 유지되고 Git에는 포함되지 않습니다. 파일이 없으면 위 기본값을 사용하며, 손상된 파일은 오류를 표시하고 임의로 초기화하지 않습니다.

T바만 빈 길이 목록을 허용합니다. 임의 길이를 채우거나 다른 자재 길이를 빌리지 않으며, T바가 BOM에 있으면 **발주 길이 미설정** 예외를 표시합니다. 기존 6종 설정 파일은 저장된 값을 그대로 읽고 T바 항목만 빈 목록으로 보완합니다. T바가 실제로 없는 BOM은 해당 설정을 입력할 필요가 없습니다.

관리자 설정 쓰기는 기본적으로 서버의 루프백 접속에서만 허용합니다. 외부·프록시 접속에서 수정하려면 서버 실행 전에 **STEELPLAN_ADMIN_PASSWORD** 환경 변수를 설정하고 화면에 해당 비밀번호를 입력하세요. 비밀번호가 설정되면 로컬에서도 입력해야 합니다. 비밀번호를 소스·Git에 저장하지 마세요. 이 설정 보호는 계정·사용자별 권한 시스템을 대신하지 않습니다.

제외 동의는 확인한 BOM·날 손실·발주 설정에만 유효합니다. 다른 사용자가 설정을 바꾸는 등 예외 대상이 달라지면 서버도 계산을 중단하고 최신 예외 목록에 대한 재확인을 요구합니다. 결과의 생산 수량과 제외 수량 합계는 원본 BOM 수량과 일치합니다.

## 실제 BOM.xls · TS BOM LIST

BIFF 형식의 `.xls`는 `xlrd`로 직접 읽습니다. `.xlsx` 변환은 필요하지 않습니다. **TS BOM LIST가 있는 통합 문서는 그 시트만 읽고** 다른 시트의 셀에는 접근하지 않습니다. 시트 선택·헤더 행·핵심 열 매핑을 서버에서도 고정하므로 화면 값을 바꾸어 다른 시트를 계산할 수 없습니다. 실제 파일의 헤더는 **5행**, 데이터는 그 아래부터입니다.

| 실제 열 | 헤더 | 사용 |
|---|---|---|
| A | Ass Mark | 조립 참조 번호 보존; Part Mark에 붙이지 않음 |
| B | Part Mark | 비고에 표시할 원본 부재 번호 |
| C | PROFILE | H빔·잔넬·C형강·환봉·T바 분류 및 규격 |
| D | Length(mm) | 절단 길이 mm |
| E | Q'ty | 해당 상세행의 필요 수량; 조립 요약 수량을 곱하지 않음 |
| G | Grade | 재질 |
| H | Area(m²) | 원본 면적 보존 |
| I | Weight(Kg) | 원본 중량 보존; 중량 해석은 사용자 지정 |

Part Mark·Grade가 없는 조립 요약행은 상세 부재와 중복 집계하지 않습니다. 다른 시트, 대상 외 PROFILE, 조립 요약행, 반복 헤더, 소계/합계행은 **가져오기 제외** 내역에 시트·행·원본 식별자·수량·사유로 표시합니다. 빈 행은 데이터로 취급하지 않습니다. 대상 상세행에 Part Mark·재질·길이·정수 수량 오류가 있으면 전체 가져오기를 중단하고 오류를 표시합니다. 없는 값을 Ass Mark나 임의 부재 번호로 보완하지 않습니다.

실제 파일의 32행은 **Ass Mark = B5 / Part Mark = WBK3**입니다. 따라서 비고는 `WBK3`이며 `B5-WBK3`로 바꾸지 않습니다. Part Mark 셀 자체가 `B5-WBK3`이면 그대로 표시합니다. 재질·규격·번호의 출력 정렬용 바깥 공백만 정리하며 내부 공백·철자·수량은 유지합니다. 바깥 공백까지 포함한 원본 셀 값은 **원본 셀 추적** 시트에 보존합니다. Ass Mark 접두사가 `T`이더라도 PROFILE이 H형강이면 H빔입니다.

제공된 실제 BOM 검증 결과는 **대상 141행·292개, Part Mark 62종**입니다. 실제 PROFILE에는 H빔·C형강·환봉이 있고 잔넬·T바는 없습니다. 다른 시트 **4개**, 대상 외 자재 **441행**, 조립 요약 **81행**, 소계·합계 **82행**을 제외 내역으로 표시합니다. 조립 요약 수량은 상세 부재와 중복되므로 이 수량들을 단순 합산하면 안 됩니다.

기본 C형강 10000mm, 날 손실 3mm/개, 실제 절단 잔재 >30mm 조건에서 다음은 제작 가능한 절단 조합이 없습니다.

| 원본 행 | Part Mark | 절단 길이 | 수량 | 사유 |
|---|---|---:|---:|---|
| 459 | MPU6 | 9990mm | 10 | 날 손실 후 잔재 7mm로 잔재 규칙 위반 |
| 464 | MPU7 | 10895mm | 5 | 10000mm 발주 길이 초과 |

두 행을 자동 분할·용접하거나 누락하지 않습니다. 기본 상태에서는 최적화를 막고, 사용자가 예외 제외를 직접 선택한 경우에 **정상 277개 + 예외 15개 = 원본 대상 292개**를 검증합니다. **Part Mark 수량 검증**을 화면·엑셀·PDF에 추가했으며 같은 Part Mark가 여러 조립·원본 행에 등장해도 합산 수요와 계획·예외 수량을 대조합니다. 원본 행별 검증과 Ass Mark 추적도 별도로 유지합니다. 발주 본수와 최적성은 계산 시간에 따라 달라질 수 있습니다.

실제 고객 BOM은 Git에 포함하지 않습니다. 회귀 테스트용 [합성 XLS 예제](tests/fixtures/ts_bom_sample.xls)는 실제 헤더 구조만 재현한 별도 데이터입니다. 고객 파일을 보유한 환경에서는 다음과 같이 실제 파일 검증을 재실행할 수 있습니다.

```bash
STEELPLAN_REAL_BOM=/path/to/BOM.xls python -m pytest -q
```

환경 변수가 없으면 실제 고객 파일 전용 테스트 하나는 건너뛰며 합성 XLS와 기존 테스트는 계속 실행합니다.

## 기존 TS ASSEM LIST 호환 양식

[TS ASSEM LIST 예제](examples/ts_assem_sample.xlsx)는 정상 6종과 각파이프 6184mm·미지원 PLT 예외를 함께 포함합니다. **TS BOM LIST가 없는 기존 .xlsx**에서만 이전 방식으로 해당 시트를 선택하며 1행 헤더를 자동 매핑합니다. 실제 BOM.xls를 읽을 때 이 시트의 부재를 추가하거나 합산하지 않습니다.

| 열 | 헤더 | 용도 |
|---|---|---|
| A | ITEM | 부재 분류 보존 |
| B | TITLE | 부재 번호 및 예외 추적 |
| C | MATL | 재질 |
| D | DESCRIPTION | 규격 및 자재 종류 판별 |
| E | LENGTH | 절단 길이 (mm) |
| F | QTY | 수량 |
| G | WEIGHT.KG | 원본 중량 보존 (최적화에는 사용하지 않음) |
| H | PAINT.M | 원본 도장 면적 보존 (최적화에는 사용하지 않음) |

2행부터 데이터를 읽고 원본 행 번호를 유지합니다. 재질·규격의 불필요한 공백은 제거하고 부재 번호 등 문자열의 앞뒤 공백을 정리합니다. 빈 행과 마지막 `TOTAL / 합계 / 총계` 등의 합계 행은 제외합니다. 합계 행은 합계 표시와 빈 절단 길이 또는 빈 규격으로 식별하므로 TITLE이 TOTAL인 정상 부재를 임의로 제거하지 않습니다.

## BOM 양식

| 재질 | 규격 | 길이 (mm) | 수량 |
|---|---|---:|---:|
| SS275 | H-300×300×10×15 | 3500 | 6 |
| SS275 | H-300×300×10×15 | 2400 | 8 |
| SM355 | H-400×200×8×13 | 4200 | 4 |

- 자동 인식 예: `재질/강종/Material/Grade`, `규격/Spec/Section/Size`, `길이/길이 (mm)/Length (mm)`, `수량/Qty/Quantity`.
- `.xls`와 `.xlsx`를 지원합니다. `.xls`는 TS BOM LIST가 필수이며, 해당 시트가 있으면 `.xlsx`도 동일한 제한을 적용합니다. 기존 `.xlsx` 양식만 수동 매핑을 유지합니다. CSV는 지원하지 않습니다.
- 모든 길이는 **mm**, 소수점 셋째 자리까지 지원합니다. 수량은 1~5,000의 정수입니다. `2,400` 같은 숫자 문자열도 읽습니다. 길이 셀에 `2400mm`처럼 단위를 붙이지 마세요.
- 최대 업로드 10MB, 압축 해제 합계 50MB, 데이터 1,000행, 총 부재 5,000개, 재질·규격 그룹 100개입니다. 행·열 탐색은 첫 30개 시트, 첫 100개 열이며 자동 헤더 탐색은 첫 30행, 수동 헤더 지정은 100행까지입니다. 데이터 읽기 자체도 10,000행 이내로 제한합니다.
- 재질·규격의 공백을 제거한 뒤 정확히 일치하는 문자열끼리 그룹화합니다. 대소문자 및 `x / × / *` 표기를 임의로 바꿔 합치지 않으므로 업로드 전에 표기를 통일하세요.
- 필수 필드 누락이나 수량·숫자 오류는 **전체 불러오기를 중단**하고 최대 50개까지 표시합니다. 자재 미지원·길이 초과·잔재 조건 예외는 별도 목록을 제공하며 직접 제외를 선택할 수 있습니다. 병합 셀은 각 행에 값을 채워 주세요.
- 수식은 실행하지 않고 Excel이 저장한 계산 결과를 읽습니다. 값이 없는 수식은 Excel에서 재계산 후 저장하거나 값으로 붙여넣으세요.

## 최적화 규칙

재질과 규격이 모두 같은 부재끼리만 절단합니다. 동일 길이의 중복 BOM 행은 합산하며, 입력 수량을 초과·미달 생산하지 않습니다. 절단하는 원자재 1본은 다음을 만족해야 합니다.

```text
제품 길이 합계 + 절단날 손실 × 부재 개수 + 잔재 = 원자재 길이
잔재 > 30mm
```

**잔재가 0~30mm인 조합은 정확히 맞는 조합을 포함해 모두 금지**됩니다. 0.001mm 정수 단위로 계산하므로 최소 허용 잔재는 30.001mm입니다. 예를 들어 6,000mm 원자재에서 부재 5,967mm를 절단하고 날 손실이 3mm이면 잔재가 30mm이므로 사용할 수 없습니다. 5,966.999mm이면 잔재 30.001mm로 허용됩니다.

날 손실 기본값은 **3mm/부재**이며 각 부재에 절단 1회를 적용합니다. 날 손실을 고려하지 않을 때는 0으로 설정합니다. 선단 트리밍·양끝 여유·가격·절단 순서 제약·별도 보유 잔재 재고는 모델링하지 않습니다. 중량 표시는 아래의 명시적 BOM 중량 해석만 사용하며 절단 최적화 목적함수에는 영향을 주지 않습니다.

목적함수는 다음 우선순위를 따릅니다.

1. **발주 본수 최소화**
2. 동일 본수에서 **총 발주 길이 최소화** (= 제품 소요량이 고정일 때 총 로스 길이 및 전체 로스율 최소화)

따라서 본수를 더 쓰면 로스가 작아지는 경우에도 본수 최소화가 우선합니다. 원자재 단가를 사용한 비용 최적화는 아닙니다.

```text
로스 길이 = 잔재 + 절단날 손실
로스율 (%) = (총 발주 길이 − 총 제품 길이) / 총 발주 길이 × 100
```

OR-Tools CP-SAT 정수계획법을 사용합니다. 먼저 실행 가능한 조합을 구하고, 그룹별로 전체 제한 시간을 나눠 더 좋은 조합을 탐색합니다. **최적해 증명 완료**는 본수와 총 길이에 대한 최적성이 증명된 경우입니다. 시간 제한 또는 모델 크기 제한(후보 본수 × (길이 종류 + 발주 길이 종류) > 30,000)에 도달하면 **실행 가능 해 · 최적해 미확정**으로 표시합니다. 이 경우 더 좋은 조합이 있을 수 있습니다. 시간 설정은 탐색 시간 예산이며 모델 생성·파일 출력 시간은 추가될 수 있습니다. 반환 전 수량과 잔재 규칙을 별도로 재검증합니다.

## 첨부 PDF에 맞춘 결과표

제공된 원자재·조합 PDF를 렌더링하여 열·배치·색상·선·머리말·꼬리말을 확인했습니다. **노란색 머리글과 소계/합계, 검은 표선, 흰 본문, 중앙 제목, 공사명·공사구분·날짜, 하단 파일명, 페이지/전체 페이지 수**를 화면·엑셀·PDF에 적용합니다. 참고 PDF의 프로젝트 데이터나 원본 파일은 GitHub에 포함하지 않습니다.

원자재 제목은 **원자재 물량 집계표**, 열은 **재질 / 규격 / 길이 / 수량 / 총중량,KG / 조합길이 / 조합중량,KG / 잔철 / 사용율 / 비고**입니다. 원자재 상세행에는 재질·규격·길이·수량을 표시하고 나머지 집계값은 참고 양식처럼 **노란색 규격 소계**에 표시합니다. 마지막에 전체 합계를 추가합니다. 소계·합계 길이는 `발주 길이 × 본수`의 합이며 사용율은 길이로 가중한 `제작 절편 길이 / 발주 길이 × 100`입니다.

조합 제목은 **조합 리스트**, 열은 **번호 / 원자재 / 수량 / 조합길이 / 잔철 / 사용율 / 길이 / 등분 / 총수량 / 총중량,KG / 비고**입니다. 재질·규격·단위중량 표시 영역을 두고 동일 패턴의 공통 열을 병합하거나 시각적으로 그룹화합니다. 재질·규격별 노란색 합계를 표시하며 PDF에서는 규격별로 페이지를 구분합니다. 긴 표에서는 공사 정보·규격과 머리글이 반복됩니다.

- `원자재`, `조합길이`, `잔철`: 원자재 1본 기준 mm. 실제 절단날 손실을 뺀 물리적 잔재를 표시합니다.
- `수량`: 해당 패턴의 원자재 본수.
- `길이`: 해당 행의 절단 길이 mm.
- `등분`: 원자재 1본에서 해당 길이로 절단하는 개수.
- `총수량`: 해당 조합에 배정된 **부재 번호별 수량**. 같은 절단 길이에 속한 행들의 총수량 합계가 `등분 × 원자재 수량`과 같습니다.
- `총중량,KG`: 중량 해석이 확인된 BOM에서 배정된 해당 절편 전체 중량. 미확인 시 공란입니다.
- `비고`: **원본 BOM 부재 번호 하나만** 표시합니다. 서로 다른 번호는 같은 절단 길이라도 별도 행이며, `× 2`, `x 3` 같은 수량 접미사나 이음 설명을 붙이지 않습니다. 부재 번호가 비어 있으면 공란을 유지하며 원본 행은 `수량 검증`에서 확인합니다. 이음 상세는 별도 `이음 제작 검토` 표에 유지합니다.

### 부재 번호별 행과 고정 표 서식

화면·엑셀·PDF는 같은 부재 번호별 행과 열 너비 비율을 사용합니다. 내용 때문에 열이 늘어나지 않으며 본문·소계·합계의 행 높이는 **24pt(화면 32px)**, 머리글은 **28pt**로 고정합니다. 숫자는 오른쪽, 비고는 왼쪽, 열 머리글은 가운데 정렬합니다. 엑셀·PDF는 선택한 A4/A3 및 인쇄 방향에 맞춰 같은 열 비율을 적용합니다.

조합번호·원자재·발주 수량·조합길이·잔철·사용율은 같은 패턴 아래 병합하거나 묶어 표시합니다. 같은 절단 길이의 **길이·등분**도 공통 셀로 묶고, 부재 번호별 **총수량**만 각 행에 표시합니다. 예를 들어 원자재 3본에서 매 본마다 2000mm를 2개씩 자르고 A 부재가 5개, B 부재가 1개이면, 등분은 기존대로 2이며 A/B 행의 총수량은 각각 5/1입니다. 부재별 등분을 임의 반올림하거나 절단 조합을 바꾸지 않습니다. 같은 번호가 여러 원본 행에 있으면 조합·절단 길이 안에서 합산해 표시하고, 원본 행별 검증은 유지합니다.

긴 문자열은 화면에서 말줄임과 전체 내용 툴팁을 제공하고, 엑셀은 셀 안에 맞춤, PDF는 최대 두 줄과 글자 폭 조절로 전체 번호를 보존합니다. 글자가 길어도 열 너비·행 높이는 바뀌지 않습니다. 매우 긴 번호는 A3 가로 인쇄나 엑셀 원본 셀에서 확인할 수 있습니다.

**소계·합계행을 상세행과 함께 다시 더하면 중복 집계됩니다.** 데이터 행만 합산하거나 규격별 합계행을 사용하세요. `수량 검증` 시트는 합계행을 포함하지 않는 원본 행 단위 검증 자료입니다.

공사명·공사구분은 입력값을 그대로 사용하고 파일명은 업로드한 BOM 이름을 사용합니다. 날짜는 한국 시간 기준 당일을 기본값으로 사용하며 변경할 수 있습니다. 첨부 예제의 공사명이나 과거 날짜를 다른 BOM에 자동 복사하지 않습니다.

### 누락 방지 검증

각 원본 행마다 `BOM 수량 = 완성 계획 수량 + 사용자 동의 제외 수량`을 대조하고, 제작 절편 수량과 길이도 별도로 검사합니다. 부재 번호가 중복되더라도 원본 행 번호와 내부 인덱스로 구분합니다. 이음 제작에서는 연결재 추가로 제작 절편 수량이 완성 부재 수량보다 많으므로 두 수치를 따로 표시합니다. 검증에 실패하면 부분 결과를 출력하지 않습니다.

화면·엑셀·PDF에 사용하는 **부재 번호별 출력 행**도 원본 행별 배정 수량과 추가 대조합니다. 이음 부재의 총수량은 본재·연결재를 합친 제작 절편 수량이므로, 원본 완성 부재 수량은 `수량 검증` 표에서 따로 확인합니다. 표시를 분리해도 계산 엔진·발주 조건·절단 패턴·발주 본수·조합길이·잔철·사용율은 유지됩니다.

기존 TS ASSEM 형식 샘플의 검증값은 **입력 17개 = 완성 계획 16개 + 미지원 자재 동의 제외 1개**, 제작 절편 **17개**, 발주 **10본**입니다. 새 실제 BOM.xls의 결과는 위 **TS BOM LIST** 절에 구분해서 기록했습니다.

### 중량은 확인된 정보만 표시

`WEIGHT.KG 해석`의 기본값은 **미지정**이며 중량은 공란입니다. 사용자가 `행 전체 중량` 또는 `부재 1개당 중량`을 직접 지정한 경우에만 BOM 값으로 조합중량을 계산합니다. 하나라도 중량이 누락·오류이면 관련 합계도 공란이며 일부 값만 합산해 전체 중량처럼 표시하지 않습니다. 원자재 kg/m·밀도·도면 단위중량을 입력받지 않으므로 **원자재 총중량은 공란**입니다. BOM 중량으로 원자재 단위중량을 역산하거나 추정하지 않습니다.

## 각파이프 이음 제작 검토

**기본 모드에서 6000mm 초과 각파이프를 6m 통재 본재와 연결재로 제작하는 검토 계획에 포함합니다. 자동 제외하거나 승인 없이 제작 확정하지 않습니다.** 이음 검토를 끄면 기존 길이 초과 예외 처리도 사용할 수 있습니다.

- 확인된 기본값: 무절단 6000mm 통재 본재, 이음 제작 여유 **5mm/이음**, 재사용 원본 잔재의 최소 길이 **5mm**. 실제 연결재 절단 후에는 항상 **30mm 초과** 잔재를 남겨야 하므로 단지 5mm 이상이라고 사용할 수 있는 것은 아닙니다.
- 6184mm 부재 1개는 본재 6000mm + 연결재 189mm − 이음 여유 5mm로 검토합니다. 날 손실은 연결재 절단에 별도로 적용합니다.
- 같은 작업의 일반 절단 계획에서 발생하는 **동일 재질·규격**의 적합한 잔재를 연결재에 먼저 배정합니다. 부족한 연결재는 기존 CP-SAT 엔진으로 추가 6m 발주를 계산합니다. 본재용 통재와 연결재용 추가 발주를 원자재 리스트에 모두 합산합니다. 별도 보유 잔재 재고를 사용하는 기능은 아닙니다.
- 통재 본재·통재 연결재는 절단 작업이 없으므로 날 손실과 잔철이 0입니다. **실제 절단 조합**은 기존의 날 손실 및 잔재 >30mm 규칙을 유지합니다.
- 원본 부재 번호별 완성 길이, 본재 길이, 연결재 길이, 통재 수, 이음 수와 상태는 별도 **이음 제작 검토** 표에 표시합니다. 조합 리스트의 비고에는 부재 번호만 표시하며 절편 길이는 길이 열에서 확인합니다. 긴 부재는 여러 통재와 연결재로 검토하므로 이음 위치·최소 연결재 길이·연결 상세를 별도로 검토해야 합니다. 프로그램이 구조 상세를 설계하거나 승인하지 않습니다.
- 이음 상세 승인 체크 전에는 **검토 필요 · 제작 확정 아님**입니다. 체크 후에도 상태는 사용자 승인 입력 사실을 표시합니다.
- 이음 모드는 일반 절단 최적화 → 적합 잔재 우선 배정 → 부족 연결재 최적화 순서입니다. 단계 전체의 최적성은 증명하지 않으므로 **최적해 미확정**으로 표시합니다. 기본 절단 엔진과 이음이 없는 일반 부재의 최적성 판정은 유지합니다.
- 완성 부재 수량과 제작 절편 수량을 별도로 표시합니다. `제작 절편 길이 − 이음 제작 여유 합계 = 완성 부재 길이`를 검증합니다. 총 로스율은 날 손실+잔철 기준이며, 이음 여유까지 포함한 **순 로스율**을 별도로 표시합니다.
- 이음 모드 엑셀에는 `이음 제작 검토`, `잔재 재사용` 시트도 추가합니다. 중량을 임의 배분하지 않으므로 이음 절편의 조합중량은 공란입니다.

실행과 계산은 Python 3.13에서 검증하며, 기존 절단 엔진 파일은 유지합니다. 화면·엑셀·PDF는 동일한 보고서 데이터를 사용합니다.
